# My Feed, My Choice?

A student philosophy project about recommendation systems and autonomy.

Website: https://ssaltuwwa.github.io/my-feed-my-choice/

The static site uses GitHub Pages. Participants can voluntarily review and submit paired before/after answers to a separate Google Form; submitted answers stay in the form owner’s account and are not committed to this public repository.

No names, email addresses, passwords or feed screenshots are requested. The initial survey findings describe 35 responses and do not demonstrate causation. The guide evaluation is separate from that baseline survey.

Development: open index.html or serve this directory with a static server. The form opens only after an explicit consent checkbox and user action.
